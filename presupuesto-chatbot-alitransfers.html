Presupuesto de Desarrollo

Implementación de chatbot web con IA para AliTransfers

Solución completa frontend + backend + despliegue

Fecha: 11/06/2026

Proyecto: Chatbot con Gemini

Validez de oferta: 15 días

Presupuesto para el diseño, desarrollo e implantación de un chatbot informativo con inteligencia artificial, integrado en la web actual de AliTransfers, incluyendo la creación del backend desde cero, conexión segura con la API de Gemini, adaptación del hosting y puesta en producción.

Alcance del proyecto

  • Diseño e integración de widget de chat en la web existente.
  • Desarrollo completo de backend en Python para exponer la API del chatbot.
  • Integración segura con Gemini AI mediante servidor intermedio para proteger la clave API.
  • Configuración de CORS, variables de entorno y estructura de despliegue.
  • Migración o adaptación a un hosting compatible con backend.
  • Configuración de entorno productivo y verificación de funcionamiento.
  • Ajuste del contexto del asistente con la información real del negocio y tarifas orientativas.
